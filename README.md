# zhCFD_HW3



计算流体力学第三次课程作业

## 前置要求

- Python 3.7+
- matplotlib,numpy第三方库
- texlive/simple Tex

## 主要内容

- 关于第三次作业的报告
- 关于第三次作业的代码





## 基本使用：

- 在hw3.tex查看报告的 latex 源码
- 查看由latex编译的hw3.pdf报告
- 在code.py查看 python 源码，通过代码生成精度验证图convergence_analysis，稳定性验证图upwind_stability、lax_wendroff_stability、warming_beam_stability，幅度衰减图amplitude_damping，相位改变图phase_error。
- 在commit.pdf查看git版本控制记录，也可以直接访问github网址https://github.com/zhehee/zhCFD_HW3#
